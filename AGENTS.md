
Preact.js app.

- use tailwind for styling
- check for type errors with `pnpm run check` after changes.
- run the Playwright tests with `pnpm test` after changes and add or update
  tests in `tests/` for new or changed features.
- use preact signals for state managent where local state is not enough
- never use try-cath unless absolutely necessary
- all ui text should be in finnish
- never use emojis in the ui, use svg icons from `src/icons.tsx` instead
